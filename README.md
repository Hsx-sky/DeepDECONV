# DeepDECONV

DeepDECONV is a Transformer-based deconvolution framework for inferring transcription initiation events and single-RNA-polymerase signal contribution functions from live-imaging nascent RNA fluorescence trajectories.

This repository provides a minimal runnable version of DeepDECONV, including the model construction code, data preprocessing functions, prediction scripts, pretrained model loading and example input data for testing.

## Overview

In live-imaging nascent RNA experiments, the observed fluorescence signal at a transcription site is a temporally accumulated signal generated by multiple elongating RNA polymerases. DeepDECONV models the observed RNA fluorescence trajectory as a convolution between:

1. a transcription initiation event series; and
2. a single-RNA-polymerase contribution function.

Unlike conventional deconvolution approaches that require a manually predefined contribution kernel, DeepDECONV uses a two-head Transformer model to infer both the initiation series and the single-RNAP contribution function directly from RNA fluorescence traces.

## Installation

This repository can be installed using a standard Python virtual environment. Conda is not required.

### 1. Clone the repository

```bash
git clone https://github.com/Hsx-sky/DeepDECONV.git
cd DeepDECONV
```

### 2. Create a Python virtual environment

On Windows PowerShell:

```powershell
python -m venv venv
venv\Scripts\activate
```

On macOS or Linux:

```bash
python -m venv venv
source venv/bin/activate
```

### 3. Install dependencies

```bash
python -m pip install --upgrade pip
python -m pip install -r requirements.txt
```

The repository was prepared using a PyCharm virtual environment. The exact package versions used in the original environment are listed in:

```text
requirements-lock.txt
```

For general use, `requirements.txt` is recommended. For exact reproduction of the original local environment, use `requirements-lock.txt`.

## Running a test prediction

After installing the dependencies and placing the pretrained model in the `Model/` folder, run:

### Windows PowerShell

```powershell
python Scripts\predict_public.py `
  --input examples\example_RNA_signals.npy `
  --model Model\deepdeconv_model.pth `
  --output results\example_test
```

### macOS or Linux

```bash
python Scripts/predict_public.py \
  --input examples/example_RNA_signals.npy \
  --model Model/deepdeconv_model.pth \
  --output results/example_test
```

The output folder will be created automatically.

## Output files

After prediction, the output directory should contain files such as:

```text
results/example_test/
├── polII_ini.npy
├── polII_contri.npy
├── RNA_input.npy
├── RNA_reconstructed.npy
└── DeepDECONV_prediction.mat
```

### Output descriptions

| File | Description |
|---|---|
| `polII_ini.npy` | Inferred transcription initiation event series. |
| `polII_contri.npy` | Inferred single-RNAP contribution functions. |
| `RNA_input.npy` | Normalized RNA fluorescence traces used as model input. |
| `RNA_reconstructed.npy` | RNA signals reconstructed from the inferred initiation events and contribution functions. |
| `DeepDECONV_prediction.mat` | MATLAB-compatible output file containing the main prediction results. |

For each input trace, DeepDECONV predicts:

1. the transcription initiation event series;
2. the single-RNAP contribution function;
3. the reconstructed RNA fluorescence trajectory.

## Input data format

The current public version uses NumPy `.npy` input files.

The input file should contain a Python dictionary. Each key is the name of one RNA fluorescence trace, and each value is a two-dimensional NumPy array with shape:

```text
[N, 1]
```

where:

- `N` is the number of time points;
- `1` indicates that each dictionary entry contains one RNA fluorescence trajectory.

Example:

```python
{
    "example_trace_00": array of shape [N, 1],
    "example_trace_01": array of shape [N, 1],
    "example_trace_02": array of shape [N, 1],
    ...
}
```

Each value should contain the RNA fluorescence intensity over time for one transcription site.

## Example data

The `examples/` folder contains a small example dataset for testing the prediction pipeline:

```text
examples/example_RNA_signals.npy
```

This example file follows the dictionary format described above:

```python
{
    "example_trace_00": np.ndarray of shape [N, 1],
    "example_trace_01": np.ndarray of shape [N, 1],
    ...
}
```

The example data are provided only for testing whether the code can be installed and executed correctly. They are not intended to reproduce the full analyses in the manuscript.

## Pretrained model

The pretrained model weight file should be placed in the `Model/` folder.

Example:

```text
Model/
└── deepdeconv_model.pth
```

The model architecture and model parameters should match the settings in:

```text
transformer_ModelParaSet.py
```

## Using custom data

To analyze your own RNA fluorescence traces, prepare a `.npy` file containing a dictionary in the following format:

```python
import numpy as np

rna_dict = {
    "trace_001": trace_001.reshape(-1, 1),
    "trace_002": trace_002.reshape(-1, 1),
    "trace_003": trace_003.reshape(-1, 1),
}

np.save("my_RNA_signals.npy", rna_dict)
```

where each `trace_xxx` is a one-dimensional RNA fluorescence trajectory with length `N`.

Then run:

```bash
python Scripts/predict_public.py \
  --input my_RNA_signals.npy \
  --model Model/deepdeconv_model.pth \
  --output results/my_prediction
```

On Windows PowerShell:

```powershell
python Scripts\predict_public.py `
  --input my_RNA_signals.npy `
  --model Model\deepdeconv_model.pth `
  --output results\my_prediction
```

## Training

This first public release focuses on prediction using pretrained models. Training scripts may be included for reference, but full model training may require additional simulated datasets, parameter settings and computational resources.

A typical training command may look like:

```bash
python Scripts/RNA_signal_translation2head_regClassify_train.py
```

Before training, please check:

```text
transformer_ModelParaSet.py
```

and make sure that the model length, input encoding, output encoding and training settings match the intended configuration.
